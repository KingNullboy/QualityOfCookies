# QualityOfCookies

A small Cookie Clicker QoL mod by KingNullboy.

## Features

- **Spacebar Clicking:** Hold Space to click the big cookie.
- **Context Menu Blocking:** Prevents the right-click context menu from appearing.
- **Third-party Achievement:** Grants the `Third-party` achievement.
- **Cheated Cookies Achievement:** Grants the `Cheated cookies taste awful` achievement.

## Versions

QualityOfCookies has separate versions for Steam and the browser.

| Directory | Platform |
|---|---|
| `Steam/` | Cookie Clicker on Steam |
| `Web/` | Browser version of Cookie Clicker |

## Installation

### Steam

1. Open Cookie Clicker.
2. Navigate to **Options → Mods → Manage Mods**.
3. Select **Open /mods folder**.
4. Copy the `Steam` folder into the `local` mods directory.
5. Enable the mod and reload the game.

### Web

1. Open Cookie Clicker in your browser.
2. Open the game's mod directory or use the browser's mod-loading method.
3. Install `Web/mod.js` using the appropriate method for your setup.
